Consistent steps every day outweigh motivation. I think small habits are important to live a better life overall, so this is a habits tracker app for Windows, Mac, and Linux. 

Tracks streaks, tasks, etc. Built in Python and CustomTkInter. 

To use, go ahead and download the latest release and run the "main.exe" file.

Started this project as a part of HackClub: The Game, but I'm continuing it on Hack Club: Horizons. I plan to continue updating this project for the foreseeable future.

To contribute, go ahead and fork the repo! I'm happy to look at any pull requests.
